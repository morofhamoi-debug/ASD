История, избранное и отчёты сохраняются только в localStorage вашего браузера

Подключение официальных API

Ключи API никогда не хранятся в этом файле. Архитектура: Browser → SPECTRA API (backend) → Official API → Result. CORS настраивается на стороне backend-прокси; попытки обхода CORS из браузера не выполняются.

Приватность и этика

Как SPECTRA обращается с данными

Какие данные используются

Только сведения, размещённые публично самими пользователями или организациями, а также данные, доступные через официальные API соответствующих платформ и сервисов.

Что сохраняется

История поисковых запросов, избранные публичные результаты и сформированные отчёты сохраняются исключительно в localStorage вашего браузера. Они не передаются на наши серверы и могут быть удалены в любой момент кнопкой «Удалить локальные данные».

Что НЕ собирается

  • Паспортные данные, СНИЛС, ИНН и любые удостоверяющие документы
  • Банковские и платёжные реквизиты
  • Пароли, токены доступа и ключи авторизации
  • Материалы из утечек и слитых баз данных
  • Скрытые адреса, приватные сообщения и закрытые контакты
  • Любая информация, доступ к которой требует обхода авторизации, CAPTCHA или ограничений платформы

Ограничение достоверности

Совпадение идентификатора (номера, ника, email, домена) не является доказательством принадлежности профиля конкретному человеку. Результаты с недостаточным количеством независимых подтверждений помечаются как POSSIBLE MATCH и никогда не отображаются как CONFIRMED OWNER.

Удаление данных

Все локальные данные удаляются мгновенно и безвозвратно через «Настройки → Удалить локальные данные» или «История → Очистить историю».
